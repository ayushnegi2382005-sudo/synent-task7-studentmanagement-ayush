# Student Management System

A command-line Student Management System built using Python.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- JSON File Storage

## Technologies

- Python
- JSON
- File Handling

## Run

```bash
python student_management.py
```

Student records are stored automatically in `students.json`.
